# How To Install To Opera GX:
1) Install the latest version of the "CasualtiesUnknownModOperaGX" folder (preferably desktop so its easy to find but you can save it anywhere in your computer)
2) Open Opera GX and go to extensions, then enable developer mode
3) Next, click "Load unpacked" and open the "CasualtiesUnknownModOperaGX" folder you downloaded.
4) It will appear in your extensions after. Make sure it is turned on or it wont work
5) If not turned on after download, go to your mods and activate them.

# (IF A NEW VERSION COMES OUT:)
1) Open Opera GX and go to extensions
2) Press the "Details" button and then "Remove extension" at the bottom
3) Go into your files on your computer, and delete the current "CasualtiesUnknownModOperaGX" folder you have installed
4) Download the newer, latest version of the mod
5) Redo install process with new version folder
